Comment cet audit a été réalisé

Cet audit est une photographie de l'état de sécurité de votre réseau à un instant donné. Il a été réalisé de façon non intrusive : aucune donnée n'a été modifiée, aucun accès non autorisé n'a été tenté. Toutes les conclusions s'appuient sur des bases de données officielles de failles de sécurité.

Phase 1 — Découverte

Diffusion ARP sur le réseau local pour identifier les machines actives. Fallback ping sweep nmap (-sn) pour les réseaux > /24. Collecte des adresses MAC pour identifier les fabricants.

Phase 2 — Scan de ports

Scan TCP SYN (nmap -sS) sur {{ total_ports }} port(s) par machine. {% if scan_profile %}Profil utilisé : {{ scan_profile }}.{% endif %} Détection de version (-sV) et d'OS (-O) activée en mode complet. Exécution parallèle sur plusieurs hôtes simultanément.

Phase 3 — Enrichissement

Corrélation avec la base NVD (NIST) via l'API CVE v2. Scripts nmap vuln/vulners pour l'extraction directe des CVE. Recherche d'exploits publics via Exploit-DB (searchsploit). {% if total_cves %}{{ total_cves }} CVE(s) distincte(s) identifiée(s).{% endif %}

Glossaire — Explication des termes utilisés

TermeCe que cela veut dire concrètement
Service accessible (port ouvert)Une "porte" de votre machine est ouverte et répond aux connexions depuis le réseau. C'est utile si c'est voulu (votre site web, par exemple), mais dangereux si c'est inutile ou mal configuré.
Service partiellement bloqué (port filtré)Un équipement de protection (pare-feu) bloque les connexions à cette porte, mais le service peut quand même être actif derrière. Moins exposé qu'un port ouvert, mais pas totalement sécurisé.
Port ferméCette "porte" est verrouillée. Aucun service ne tourne derrière et personne ne peut y accéder. C'est l'état idéal pour tout ce qui n'est pas indispensable.
Risque critiqueUne faille qui permettrait à un pirate de prendre le contrôle total d'une machine, de voler vos données ou de bloquer votre activité. À traiter aujourd'hui.
Risque élevéUne faille sérieuse qui pourrait permettre l'accès à des informations confidentielles ou perturber un service. À corriger sous 48 heures.
Risque modéréUn point de vigilance qui faciliterait une attaque si d'autres failles s'y ajoutaient. À corriger dans les deux semaines.
Outils d'attaque publics disponiblesDes programmes permettant d'exploiter cette faille existent sur Internet et sont accessibles à n'importe qui. Cela rend l'attaque beaucoup plus probable et facile.
ServeurUne machine qui fournit des services à d'autres (votre site web, votre messagerie, votre base de données…). Généralement plus critique à sécuriser.
Poste de travailL'ordinateur de bureau ou portable d'un employé. Moins exposé qu'un serveur, mais reste une cible pour les attaques.
Passerelle (routeur)L'équipement qui fait le lien entre votre réseau interne et Internet (votre box ou routeur). Pièce maîtresse de la sécurité réseau.
Faille de sécurité référencéeUne vulnérabilité officiellement reconnue et enregistrée dans une base de données internationale. Sa présence est confirmée par des experts en sécurité.
Audit de sécuritéUne analyse complète de votre réseau visant à identifier les points faibles avant qu'une personne malveillante ne les découvre.
