Glossaire

TermeDéfinition
Port ouvertUn service actif sur la machine répond à ce port. Il est accessible depuis le réseau et potentiellement exploitable.
Port filtréUn pare-feu bloque les connexions à ce port. Le service peut être actif mais masqué.
Port ferméAucun service ne tourne sur ce port. Le port est inaccessible.
Vulnérabilité critiqueFaille permettant potentiellement à un attaquant de prendre le contrôle de la machine. Nécessite une action immédiate.
Vulnérabilité élevéeFaille sérieuse pouvant compromettre la confidentialité ou l'intégrité des données. Correction urgente recommandée.
Exploit publicUn programme permettant d'attaquer cette vulnérabilité est disponible publiquement, augmentant le risque d'attaque.
Taux d'expositionPourcentage des ports vérifiés qui sont ouverts ou filtrés. Un taux faible indique une meilleure maîtrise de la surface d'attaque.
ServeurMachine fournissant des services réseau (web, base de données, messagerie…). Généralement plus exposée.
Poste de travailMachine utilisée par un employé pour ses tâches quotidiennes (PC, laptop…).
PasserelleÉquipement qui relie plusieurs réseaux (routeur, box Internet…). Critique pour la sécurité du réseau.
ARPProtocole de découverte réseau utilisé pour lister les machines actives sur un réseau local.
Scan de portsTechnique permettant d'identifier les services actifs sur une machine en testant chaque port réseau.
